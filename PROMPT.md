# Как сгенерировать новую историю

Самый быстрый путь — прямо в приложении: на экране «Добавить историю» сохрани свой Anthropic API-ключ (один раз, хранится только в браузере) и жми **«Сгенерировать историю»** — история создастся и откроется сама.

Если ты нашла готовый немецкий текст (статью, рассказ), его можно загрузить как есть: раздел **«Загрузить готовый текст»** на том же экране. Текст останется дословным — ИИ только добавит глоссы к сложным словам, словарь и обложку. Работает и через API-ключ в один клик, и через копипаст промпта в любой ИИ-чат.

Запасной путь — вручную: приложение само собирает персональный промпт, нажми **«Скопировать промпт»** — в него автоматически подставятся твои оценки сложности прочитанных историй, слова, которые ты учишь, и слова, которые тебе уже знакомы.

Дальше:

1. Вставь промпт в любой привычный ИИ-чат — [Claude](https://claude.ai), [ChatGPT](https://chatgpt.com), [Gemini](https://gemini.google.com) и т.п. (формат общий, модель не важна).
2. Получи в ответ JSON истории.
3. Сохрани его как `src/stories/<id>.json`.
4. Добавь импорт в `src/stories/index.ts`:

```ts
import meineNeueGeschichte from './meine-neue-geschichte.json'

export const stories: Story[] = [
  // ...существующие,
  meineNeueGeschichte,
]
```

5. Закоммить и запушь — GitHub Pages пересоберётся автоматически.

## Формат истории

```json
{
  "id": "kebab-case-id",
  "title": "Заголовок на немецком",
  "titleRu": "Перевод заголовка",
  "level": "A1",
  "paragraphs": [
    "Текст абзаца. Сложные слова размечаются так: {{Wort|перевод}}.",
    "Ещё абзац..."
  ],
  "dict": { "слово": "перевод в контексте" }
}
```

Правила разметки:
- `{{Wort|перевод}}` — слово или выражение целиком ({{zu Hause vergessen|забыл дома}}) в той форме, в которой стоит в тексте; перевод короткий, на русском.
- Разорванные единицы (отделяемая приставка, Perfekt): позднюю часть помечай `{{+auf}}` — «Er {{steht|встаёт (aufstehen)}} früh {{+auf}}.» Перевод только у первой части, с инфинитивом. Саму приставку помечай ВСЕГДА — не отправляй её смысл в `dict`.
- Предлог при глаголе переводи по смыслу конструкции и помечай ИНЛАЙН, а не общим значением в `dict`: «er {{denkt|думает о (denken an)}} {{+an}} das Wasser» (denken an — думать о, warten auf — ждать, sich freuen über/auf — радоваться, fragen nach — спрашивать о). Один и тот же предлог значит РАЗНОЕ в разных местах (an der Tür — у двери; denkt an — думает о; zieht … an — надевает), поэтому такие места решай прямо в тексте.
- Между двумя частями разорванной пары (`{{…|…}} … {{+часть}}`) не ставь других маркеров `{{...}}` — иначе `{{+…}}` привяжется не к тому слову; если слово между ними надо пояснить, положи его перевод в `dict`.
- Глоссируй каждую единицу только при первом появлении.
- 8–12 глосс на историю, 120–180 слов, 4–6 абзацев.
- `dict` — переводы всех остальных слов текста (ключи в нижнем регистре, без имён собственных), по смыслу в контексте истории; части составных форм объясняются с отсылкой к целому. У каждого слова ОДНО чистое значение в его роли; не смешивай несколько смыслов и не добавляй отсылок к другим словам («также: …»). Для служебных слов (an, auf, zu, in) оставляй базовое значение предлога — особые смыслы уже помечены инлайн.
- `cover` (опционально) — обложка: плоский SVG одной строкой, viewBox="0 0 640 360", одинарные кавычки в атрибутах, без текста и скриптов. Показывается в списке историй и над текстом.

Тап по любому слову текста показывает перевод: сначала ищется глосса, потом `dict`; если слова нет нигде — приложение предложит внешний переводчик.
